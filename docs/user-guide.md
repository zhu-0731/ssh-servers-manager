# 使用说明

## 启动

推荐使用 GitHub 发行页中的 `SSH-Servers-Manager-v0.1.3-win-x64-Setup.exe`。按向导选择目录和可选桌面快捷方式，完成后从开始菜单启动。默认安装到当前用户目录，无需管理员权限，内置 .NET 运行时。

卸载可通过 Windows“已安装的应用”或开始菜单卸载入口进行；卸载保留原有连接配置和凭据，重新安装后可继续使用。覆盖升级前先从托盘彻底退出旧实例。

GitHub 便携发行包：解压 ZIP 后运行 `SshServersManager.exe`，包内已包含运行时，无需另行安装 .NET。

源码工作区：双击项目根目录的 `start.cmd`。如果已构建本地程序，会直接打开；否则通过 .NET SDK 从源码运行。

也可以直接打开 `artifacts/windows-x64-v0.1.3/SshServersManager.exe`。当前发布包需要 .NET 8 Desktop Runtime（x64）。运行软件不要求管理员权限。更新后先从托盘退出旧实例，再启动新版，原有配置保持共用。

## 首次建立通道

1. 打开“配置 → SSH 服务器”，新增服务器，填写名称、IP 或域名、SSH 端口与用户名。
2. 默认选择“用户名和密码（无需私钥）”，填写 SSH 登录密码即可。选择“私钥文件”时，路径留空会自动查找常用密钥，或点击“查找本机常用私钥”选择已发现文件，也可手动浏览其他位置。无口令私钥无需填写口令。凭据留空保留同一认证方式的旧值；认证方式变化时，旧凭据不继续复用。
3. 新建或选择方案，点击“新增规则”。
4. 选择服务器和方向，填写监听地址、监听端口、目标地址、目标端口。
5. 点击规则右侧“启动”，首次连接需通过可信渠道核对主机指纹后确认。
6. 使用相应监听端点访问服务。表格“运行中”表示监听建立，不表示目标服务健康。

监听地址需要填写 IP，支持 IPv4/IPv6；服务器与目标地址支持域名。IPv6 端点复制时使用 `[地址]:端口`。

终端 `ssh 用户名@主机` 可能自动读取默认密钥、SSH Agent 或 `~/.ssh/config`。软件现在会查找 `%USERPROFILE%\.ssh` 和 `HOME` 指向目录的 `.ssh`，先按 `id_ed25519`、`id_ecdsa`、`id_rsa` 顺序，再尝试这些目录中的 `.pem`、`.key`、`.ppk`（每目录最多 16 个扩展名候选）。不递归扫描、不把 `.pub` 或 `known_hosts` 当作私钥；查找按钮只读取文件名，连接时才读取私钥内容。

路径留空会尝试找到的可读取密钥，跳过无法解析或解密的候选；若私钥有口令，需要填写相应口令。手动指定文件时只使用该文件，支持 `~` 和 `%USERPROFILE%` 路径。当前不读取 SSH Agent、`ssh config` 中的 IdentityFile 或硬件安全密钥，因此终端能连接但本工具未找到密钥时，仍可手动选择实际私钥。

## 两种方向

- 本地转发：本机监听，目标地址由 SSH 服务器访问。例如本机 `127.0.0.1:13306` → 远端内网 `10.0.0.5:3306`。
- 远程转发：SSH 服务器监听，目标地址由 Windows 本机访问。例如服务器 `127.0.0.1:18080` → 本机 `127.0.0.1:8080`。

默认回环监听仅允许监听机器本身访问。远程转发需要 SSH 服务端允许转发；监听公网/局域网地址还取决于服务端 GatewayPorts 等策略、防火墙和网络路由。

## 从 SSH 命令导入

点击工具栏“导入 SSH 命令”，或“配置 → 从 SSH 命令导入”。粘贴一条命令后点击“解析并预览”，核对服务器、方向、监听范围和目标端点，再选择已有方案或新方案保存。保存只新增配置，全部保持停止；不执行命令，不覆盖已有服务器。

例如：

```text
ssh -p 2222 -N -L 13306:10.0.0.5:3306 dev@192.0.2.10
ssh -i "C:\Users\Test User\.ssh\id_ed25519" -R 18080:127.0.0.1:8080 dev@192.0.2.10
ssh -NT -L 13306:10.0.0.5:3306 -R 18080:localhost:8080 dev@192.0.2.10
```

支持 `user@host`、`ssh://user@host:port`、`-p`、`-l`、一个私钥文件 `-i`、多个 `-L/-R`，以及附着参数（如 `-p2222`）和组合标志（如 `-NT`）。带空格的路径需要引号；多行粘贴支持反斜杠、PowerShell 反引号和 CMD `^` 的换行续写。

`-o` 仅支持 Port、User、HostName、IdentityFile、ConnectTimeout、LocalForward、RemoteForward、PreferredAuthentications。其中认证值只支持单一 `password` 或 `publickey`。不支持的选项明确报错，不静默忽略；重复且不一致的单值选项也会报错。

未指定用户名时暂用当前 Windows 用户名，并在预览提示修改。未指定认证方式时默认私钥自动查找，预览下方可以切换为密码。密码与私钥口令不从命令读取，保存后通过服务器管理填写。

省略监听地址使用 IPv4 回环 `127.0.0.1`，不是 OpenSSH 可能建立的双栈监听。`localhost` 监听也统一为 IPv4 回环；`-g` 使省略地址的本地规则监听 `0.0.0.0`，远程规则仍默认回环。显式 `*` 或空监听地址也映射为 `0.0.0.0`。预览会提示通配地址的对外开放范围。

IPv6 地址使用方括号，例如 `-L [::1]:13306:[2001:db8::5]:3306`。若无 `-L/-R`，仅保存服务器。终端/后台/输出标志由桌面软件管理，预览中提示；`-C` 不启用压缩。动态 SOCKS `-D`、跳板 `-J`、外部配置 `-F`、Unix socket、远程命令、管道、重定向及 shell 命令替换暂不支持。

命令只在导入窗口内解析，不写入配置或日志；没有执行或 shell 展开。部分格式参考 [OpenSSH 命令手册](https://man.openbsd.org/ssh.1)，具体支持范围以本节为准。

## 批量、复制与编辑

- 只有勾选复选框的行显示浅蓝底，未勾选的行始终保持白底；点击行仅定位，不代表勾选。
- “启动勾选”“停止勾选”“重连勾选”“删除勾选”仅处理勾选规则；未勾选时提示先勾选。“启动方案”“停止方案”处理当前方案全部规则。
- “复制勾选到”支持复制到已有方案，或输入名称创建新方案。
- 左侧“复制”复制当前整个方案。副本默认停止，配置修改彼此独立；服务器配置继续共用。
- 当前需要先停止规则再编辑；服务器有活动规则时需要先停止关联规则再编辑。
- 编辑规则针对当前点击的行；右键复制针对右键点击的行。单条启停可直接点击该行“操作”按钮，无需勾选。
- 可保存使用相同端口的备用方案，同时启动时会报告冲突。

启动结果会陆续显示在各行。批量操作中某条失败不影响其余规则。正在连接或等待重连的规则也可以停止。

## 保存、导入导出与凭据

配置自动保存到 `%LOCALAPPDATA%\SshServersManager\config.json`，上一版本保存在 `config.json.bak`。打开“配置 → 打开数据目录”可以查看。

密码与私钥口令位于当前 Windows 用户的凭据管理器，目标名前缀为 `SshServersManager/`。配置、日志及导出不保存这些秘密。私钥由用户提供，软件仅在本机配置保存路径。

导出全部配置包含服务器地址、用户名和端口规则，请只与合适的人分享。导出不含凭据、私钥路径和主机信任记录。导入为合并操作，生成新 ID，不覆盖原配置；私钥路径为空，在新机器上自动查找，必要时重新选择文件或填写口令。

配置损坏时软件不会静默重置或覆盖。退出软件后先备份数据目录，再检查配置或将 `.bak` 恢复为 `config.json`。

## 托盘与重连

点击窗口右上角叉号，每次都会询问关闭方式：

- “最小化到托盘”：保存配置、隐藏窗口，通道继续运行。
- “彻底退出”：保存配置、停止全部受管通道并退出。
- “取消”（或关闭提示窗口）：返回主界面。

托盘使用专用的深蓝色终端与青色箭头图标，窗口和程序文件也使用相同图标。双击托盘图标恢复界面；托盘菜单“退出并停止全部”可直接退出。重新启动软件不会自动连接。

自动重连默认关闭，按规则启用。它仅在成功连接后掉线时生效，采用最长 30 秒的退避；初次连接失败、认证或信任失败需要用户处理。手动停止会取消重试。

异常终止或系统关机时无法保证完成应用层清理；重新启动后不沿用上次运行状态。休眠唤醒后的状态依赖 SSH 保活和网络检测，具体延迟仍需真实设备验证。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 缺少密码 | 编辑服务器并填写密码；导入不携带凭据 |
| 认证失败 | 检查用户名、密码、私钥和服务端认证策略 |
| 私钥不存在 | 在服务器编辑页重新选择本机私钥 |
| 监听失败 | 检查端口占用、监听地址是否存在、SSH 服务端转发策略 |
| 运行中但服务不可达 | 核对目标地址的访问视角，检查目标服务和防火墙 |
| 主机指纹变化 | 停止连接，先经可信渠道核验；退出软件、备份并手动维护 `known-hosts.json`，不要直接忽略异常 |
| 界面关闭但端口仍占用 | 检查系统托盘，选择停止全部或退出 |

当前日志仅在内存保留最近 500 条，不写入磁盘；重启会清空。
