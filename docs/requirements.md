# 需求规格

状态：第一版范围已确认。实现方式尚待选型，本文不表示功能已经实现。

## 1. 目标与平台

第一版仅支持 Windows 桌面。保存 SSH 服务器和端口规则，通过方案组织常用连接，一键建立或停止隧道，并独立管理每条规则。同一方案需要支持多台服务器和双向转发。

## 2. 配置对象

| 对象 | 字段 | 关系 |
| --- | --- | --- |
| SSH 服务器 | 名称、IP/域名、SSH 端口（默认 22）、用户名、认证方式、凭据引用、超时和保活设置 | 可被多条规则引用 |
| 方案 | 名称、备注 | 包含多台服务器的规则 |
| 端口规则 | 名称、服务器引用、方向、监听地址和端口、目标地址和端口 | 归属一个方案，独立运行 |

端口必须为 1–65535 的整数。每个对象使用独立 ID，名称和地址不作为主键。

## 3. 转发方向

| 方向 | 监听位置 | 目标访问视角 | 示例 |
| --- | --- | --- | --- |
| 本地转发 `-L` | Windows 本机 | SSH 服务器侧 | 本机 `127.0.0.1:13306` → SSH 服务器 → 内网数据库 `10.0.0.5:3306` |
| 远程转发 `-R` | SSH 服务器 | Windows 本机侧 | SSH 服务器 `127.0.0.1:18080` → SSH 隧道 → 本机网站 `127.0.0.1:8080` |

界面明确说明监听位置和目标访问视角。默认只监听回环地址；对外开放需显式设置，远程监听还受服务器 SSH 策略约束，不能承诺仅修改客户端即可对外开放。

## 4. 规则管理

- 新增、编辑、删除和复制规则。
- 独立启动、停止和重连；重复点击启动不产生重复隧道。
- 展示未启动、连接中、运行中、停止中、异常和具体错误。
- 复制监听端口、目标端口或访问地址；不为所有服务默认添加 HTTP 前缀。
- 修改运行中的规则时提示重启生效，保留实际生效配置的快照。
- 停止或重启一条规则，不影响其他规则，包括使用同一服务器的规则。
- 删除运行中的规则需提示并先停止该规则。

## 5. 方案与复制

- 新建、重命名、删除方案，自动保存有效配置。
- 一键启动、停止当前方案，也可勾选规则批量操作。
- 批量启动时逐条报告结果，一条失败不阻止其他规则启动。
- 复制整个方案，或将选中规则复制到已有方案、新方案。
- 复制项使用新 ID，修改彼此独立，不复制运行状态，默认停止。
- 复制规则默认引用原 SSH 服务器，可重新选择服务器、地址和端口。
- 允许备用方案保存相同监听端口，启动时检查冲突。
- 导入导出默认不含密码、私钥内容和口令；导入后可重新关联凭据。
- 删除方案需提示并停止关联规则；被引用的服务器不能静默删除。

## 6. 冲突与故障

- 本地监听按地址、端口和地址族检查占用，考虑通配地址与具体地址的冲突。
- 远程监听检查已知冲突，最终以服务器接受监听的结果为准。
- 不同服务器允许使用相同远程端口；同一主机的多个配置别名不能作为无冲突依据。
- 区分认证失败、主机指纹问题、监听失败、连接中断和目标连接失败。
- “运行中”表示隧道与监听已建立，不等于目标服务正常；目标可达性需有实际连接或探测证据。
- 掉线后更新关联规则状态。支持手动重连和可选自动重连；手动停止后禁止自动拉起。

## 7. Windows 生命周期与安全

- 支持密码和私钥认证；密码与私钥口令存入 Windows 安全存储，配置仅保存引用。
- 首次连接确认主机指纹；指纹变化不得静默通过。
- 关闭窗口默认最小化到托盘并保持隧道，首次操作时说明。
- 托盘支持打开界面、停止全部和退出。
- 明确退出时停止本软件管理的全部隧道，不结束其他程序的 SSH 进程。
- 重启后恢复配置，默认不自动启动，也不沿用旧运行状态。
- 正确处理休眠唤醒、断网与异常退出，避免状态失真和失控残留连接。
- 日志不含密码、私钥内容或口令，诊断导出需支持敏感连接信息清理。

## 8. 界面

左侧方案列表，右侧规则表格，底部或侧栏日志。表格展示名称、服务器、方向、监听端点、目标端点、状态和操作。服务器配置单独管理。

## 9. 第一版验收标准

1. 保存并重新加载服务器、方案与规则，凭据不明文落盘。
2. 同一方案可启动两台服务器的规则，通过真实 TCP 服务验证本地和远程转发。
3. 停止或重启任意规则，其他运行规则保持连接。
4. 复制方案和跨方案复制规则后，ID 与配置修改互相独立，复制项停止。
5. 端口占用、认证失败、远端拒绝监听和掉线显示准确状态与可理解错误。
6. 批量操作中单条失败不影响其余规则，结果可逐条查看。
7. 托盘隐藏保持连接，明确退出释放受管监听，重新打开不自动启动。
8. 首次主机指纹需确认，变化不得静默接受。
9. 导入导出不泄露凭据，缺失凭据可补充。

## 10. 暂不纳入第一版

动态 SOCKS 代理（`-D`）、多级跳板机、开机自动连接、流量统计、macOS/Linux 客户端和云端同步。

## 11. SSH 命令解析导入（追加需求）

- 粘贴 SSH 命令，解析服务器、用户名、端口、私钥及多条本地/远程转发规则。
- 先预览，再选择方案保存，所有导入规则默认停止。
- 支持常用选项、引号与 IPv6；不支持的语义明确报错，不静默执行或丢弃。
- 原始命令不持久化、不执行，不调用 shell；密码与口令通过凭据管理另行配置。
- 导入新增服务器，不覆盖现有连接；保存失败不改变内存配置。
- 具体支持范围见使用说明中的“从 SSH 命令导入”。
