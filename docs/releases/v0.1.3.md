# SSH Servers Manager v0.1.3

首个 Windows x64 公开预览版。

推荐下载 `SSH-Servers-Manager-v0.1.3-win-x64-Setup.exe`，使用中文向导安装，可选择目录及桌面快捷方式，提供开始菜单和 Windows 卸载入口。默认只安装给当前用户，不需要管理员权限。

也可下载 `SSH-Servers-Manager-v0.1.3-win-x64.zip`，解压后运行 `SshServersManager.exe`。两种分发形式使用相同应用，均内置 .NET 8.0.32 Desktop Runtime，无需另行安装 .NET。

## 功能

- 多服务器、多方案管理，本地 `-L` 和远程 `-R` 转发，规则独立启停。
- 规则与方案复制、批量操作、配置导入导出。
- SSH 命令解析、预览及导入，支持常用选项和 IPv6 地址写法。
- 密码与私钥认证、常用私钥自动查找、主机指纹确认及 Windows 安全凭据存储。
- 复选框明确标记批量操作范围；关闭时可选托盘、彻底退出或取消。
- 专用程序与托盘图标，连接日志及可选自动重连。

## 验证

- 源码版本完成 32 项基础和真实 SSH 集成检查，Release 构建无警告、无错误。
- UI 回归覆盖勾选颜色、空勾选保护、取消关闭、保存到托盘和退出清理。
- 自包含便携包额外执行隔离的界面启动与关闭检查。
- Setup 额外检查安装、开始菜单快捷方式、安装后 UI、重复安装、卸载及用户文件保留。
- ZIP 与 Setup 各附 `.sha256` 用于检查完整性，包内 `build-info.json` 记录应用来源提交与运行时版本。

## 已知限制

- 当前仅提供 Windows x64，程序和安装器尚未代码签名。
- 尚未在无 .NET 的干净 Windows 机器上人工验收；已采用自包含发布并执行本机运行检查。
- 尚未接入 SSH Agent、完整 ssh config、跳板机、动态 SOCKS 和开机自动连接。
- 运行中规则需先停止再编辑；不同 OpenSSH 策略、IPv6 网络和休眠唤醒仍需更多环境验证。
- 主机信任记录维护和配置备份恢复目前需手动操作。

用户配置保存在 `%LOCALAPPDATA%\SshServersManager`；密码和私钥口令位于 Windows 凭据管理器。发行包不包含个人配置、真实服务器数据、私钥、口令或测试运行文件。第三方许可文件随包提供。
